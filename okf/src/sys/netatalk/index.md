# src/sys/netatalk

* [aarp.c](aarp.c.md) - AARP: AppleTalk address resolution in the BSD kernel stack.
* [aarp.h](aarp.h.md) - AppleTalk Address Resolution Protocol packet and cache types.
* [at.h](at.h.md) - AppleTalk socket addresses, network ranges and protocol constants.
* [at_control.c](at_control.c.md) - AppleTalk interface ioctls and address setup in the BSD kernel stack.
* [at_proto.c](at_proto.c.md) - AppleTalk protocol switch and domain in the BSD kernel stack.
* [at_var.h](at_var.h.md) - Kernel AppleTalk interface address state and configuration types.
* [ddp.h](ddp.h.md) - ELAP and DDP packet header types, field aliases and size constants.
* [ddp_input.c](ddp_input.c.md) - DDP input: packet delivery and forwarding in the BSD kernel stack.
* [ddp_output.c](ddp_output.c.md) - DDP output and routing in the BSD kernel stack.
* [ddp_usrreq.c](ddp_usrreq.c.md) - DDP socket requests and control blocks in the BSD kernel stack.
* [ddp_var.h](ddp_var.h.md) - Kernel DDP socket control blocks, statistics and lookup interface.
* [endian.h](endian.h.md) - Platform byte order detection and endian constants.
* [phase2.h](phase2.h.md) - IEEE 802.2 LLC and SNAP header types for AppleTalk Phase 2.
