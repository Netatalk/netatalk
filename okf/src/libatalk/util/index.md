# src/libatalk/util

* [afp_util.c](afp_util.c.md) - Names of AFP command and result codes for log messages.
* [atalk_addr.c](atalk_addr.c.md) - Parsing of AppleTalk addresses in text form.
* [bprint.c](bprint.c.md) - Hex dump of a buffer to stdout.
* [cnid.c](cnid.c.md) - CNID resolution of paths, and volume UUIDs without dashes for CNID table names.
* [constant_time.c](constant_time.c.md) - Constant-time memory comparison.
* [fault.c](fault.c.md) - Fault signal handlers with backtraces, from Samba.
* [getiface.c](getiface.c.md) - Lists of the network interface names of the system.
* [gettok.c](gettok.c.md) - Line tokenizer for configuration files, used by the extmap.conf reader.
* [locking.c](locking.c.md) - Netatalk utility functions: locking.
* [logger.c](logger.c.md) - The netatalk logging system: log types, levels, files, and syslog.
* [netatalk_conf.c](netatalk_conf.c.md) - Reading afp.conf and extmap.conf: server options, volume definitions, and the extension map.
* [pathconv.c](pathconv.c.md) - UTF-8 to Mac file name conversion with mangling.
* [queue.c](queue.c.md) - Netatalk utility functions: queue.
* [server_child.c](server_child.c.md) - functions to handle child processes
* [server_ipc.c](server_ipc.c.md) - IPC over socketpair between parent and children.
* [server_lock.c](server_lock.c.md) - Pid files and daemonizing of the netatalk servers.
* [sigpipe.c](sigpipe.c.md) - Self-pipe that wakes a poll loop from signal handlers.
* [socket.c](socket.c.md) - Netatalk utility functions: socket.
* [strdicasecmp.c](strdicasecmp.c.md) - Case-insensitive string comparison through the Mac Roman uppercase map.
* [unix.c](unix.c.md) - Netatalk utility functions: unix.
